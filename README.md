## The joke

> At 11:58, two minutes before the deadline, Rina's printer jammed on page 47 of 48 — and the one page it did print was stamped 'DO NOT PRINT'.

A scene, not a quip: 11:58, two minutes before the deadline; Rina; the printer jamming on page 47 of 48; and the turn — the only page it printed was the one stamped 'DO NOT PRINT'.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the entry is exactly one line of 1–200 characters, writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads it back to verify the write.
